# ADB 多区域随机点击器

Windows 电脑端配置界面，使用 Python 自带 Tkinter，无第三方 Python 依赖。

## 启动

需要 Python 3.10 或以上（含 Tkinter）和 Android SDK Platform Tools 中的 adb.exe。
手机打开开发者选项、USB 调试，连接电脑并在手机上允许调试。

在本目录的 PowerShell 执行：

```powershell
python .\adb_clicker.py
```

也可运行 `start.ps1`。如果 PowerShell 策略禁止脚本，直接使用上面的 Python 命令。

## 配置与执行

1. ADB 在 PATH 中时保留 `adb`，否则点击“选择 adb.exe”。刷新并选择设备。
2. 点击“截图框选”，在截图中拖动矩形并“使用选区坐标”。也可手动填坐标。
3. 填写名称和该区域每轮最少、最多点击次数，点击“添加区域”。重复添加多个区域。
4. 选中已有区域可修改后“更新选中”，或删除、上移、下移。
5. 设置轮间隔范围（默认 20～22 秒）、同一区域内相邻点击间隔（默认 0.2～0.5 秒）、区域间隔（默认 1～2 秒）。循环轮数 0 表示无限。
6. 点击“开始”，用“停止”结束。可保存和加载 JSON 配置。

每轮先等待随机轮间隔，然后按列表顺序执行所有区域。每个区域每轮独立随机抽取点击次数，
每一次点击独立随机抽取区域内整数坐标。两个相邻区域之间独立随机等待区域间隔，不叠加区域内点击间隔。
轮间隔从上一轮完成后计算，因此每轮开始时间差包含上一轮执行耗时；第一轮也会等待。
相同上下限表示固定值；坐标上下限包含端点。坐标原点在设备屏幕左上角。

例如区域 A 每轮 1～3 次、区域 B 每轮 2～4 次：每轮先等 20～22 秒，
点击 A 1～3 次，等待 1～2 秒，再点击 B 2～4 次，随后开始下一轮等待。

截图缩放只影响预览，框选结果转换为设备实际像素坐标。框选仅填写编辑框，必须添加或更新区域才会生效。
开始前会读取屏幕截图并检查所有区域边界；运行期间请保持屏幕方向、分辨率及目标页面不变。
本工具不识别界面元素，也不会自动唤醒或解锁设备。运行期间配置锁定，停止后再修改。
停止可以立即中断等待，但已发出的 ADB 命令需返回或超时（15 秒），已发送的点击无法撤回。
ADB 失败会终止任务并显示错误，不会自动重试点击。

## 验证

```powershell
python -m unittest discover -s tests -v
python -m compileall -q adb_clicker.py click_engine.py tests
```

自动测试使用模拟 ADB，不会向手机发送真实点击。连接设备后的点击效果需在目标手机确认。
