# ADB 多区域随机点击器

Windows 电脑端配置界面，使用 Python 自带 Tkinter，无第三方 Python 依赖。

## 启动

**将 `dist/AdbClicker-portable.zip` 完整解压，双击 `AdbClicker.exe` 启动，无需安装 Python、ADB 或配置 PATH。**
本机可直接双击 `dist/AdbClicker.exe`。EXE 已包含 Python 和 Tkinter，旁边的 `adb/` 文件夹包含 ADB 及所需 DLL。
分发时请发送完整 ZIP，不要只复制 EXE。程序默认使用内置 ADB；也可手动指定其他版本，或点击“使用内置 ADB”切回。
Windows 仍需要识别手机的 USB 调试接口；若设备管理器不能识别手机，需安装该设备厂商提供的 USB 驱动。
手机打开开发者选项、USB 调试，连接电脑并在手机上允许调试。

仅开发时从源码启动才需要 Python 3.10 或以上（含 Tkinter），在本目录的 PowerShell 执行：

```powershell
python .\adb_clicker.py
```

也可运行 `start.ps1`。如果 PowerShell 策略禁止脚本，直接使用上面的 Python 命令。

## 重新打包（开发用）

执行 `build.ps1`，会在项目的 `.build-venv` 中安装 `requirements-build.txt` 指定的 PyInstaller，
生成无控制台窗口的 `dist/AdbClicker.exe`，复制项目 `vendor/adb/` 到 `dist/adb/`，并生成可分发的 `dist/AdbClicker-portable.zip`。
ADB 保持为 EXE 旁的独立文件，避免单文件临时解压目录被后台 ADB 服务占用。PyInstaller 仅作为构建依赖，用于打包 Python、Tkinter 和程序代码。
修改源码后需要重新打包，已生成的 EXE 不会自动更新。`build/`、`dist/` 和构建环境不纳入 Git。

## 配置与执行

1. 保留默认的“内置 ADB”，点击“刷新设备”并选择设备；不需要配置系统 PATH。
2. 折叠屏或多屏设备可点击“刷新屏幕”，按尺寸和点亮状态选择内屏或外屏；默认“自动选择主屏”。
   点击“采集屏幕并框选”，工具通过 ADB 读取所选屏幕的当前图片并显示。截图不会向手机存储写入文件。
3. 在图片上按住鼠标左键拖出矩形，填写名称、该区域每轮最少/最多点击次数、完成后等待的最小/最大秒数，点击“添加此区域”。
   已添加区域以绿色框显示，可在同一张截图中连续框选、添加多个区域，最后点击“完成框选”。
4. 选中已有区域可修改后“更新选中”，或删除、上移、下移。
5. 每个区域单独设置“完成后等待”范围（默认 1～2 秒）。全局设置轮间隔范围（默认 20～22 秒）、同一区域内相邻点击间隔（默认 0.2～0.5 秒）。循环轮数 0 表示无限。
6. 点击“开始”，用“停止”结束。左侧配置列表可快速保存、更新、加载和删除 JSON 配置。

## 配置列表

- 默认扫描程序目录的 `configs/`：源码版为项目根目录下，EXE 版为 EXE 旁的文件夹；不受启动工作目录影响。
- 将已有 JSON 配置复制进去后点击“刷新”，或使用“选择目录”切换扫描目录（仅本次运行有效）。只列出当前目录中的 JSON 文件，不递归扫描。
- 填写配置名称，点击“另存为新配置”；同名文件不会被覆盖。
- 双击列表项或点击“加载选中”即可加载。修改区域后先点击“更新选中”，再点击“更新当前配置”保存。
- “更新当前配置”更新的是当前已加载的文件，单击其他列表项不会改变更新目标。
- “删除选中”经确认后删除对应文件；删除当前配置后，界面参数仍保留，可以另存。
- “从文件加载…”和“导出配置…”保留原来的文件对话框功能；外部文件加载后可另存到列表目录。
- 写入采用临时文件加原子替换，写入失败时保留原文件。错误配置加载失败时保留当前界面参数。
- 发布 ZIP 只包含空配置目录的说明，不包含你的个人配置；重新打包不覆盖已有 `dist/configs/*.json`。

每轮先等待随机轮间隔，然后按列表顺序执行所有区域。每个区域每轮独立随机抽取点击次数，
每一次点击独立随机抽取区域内整数坐标。区域的全部点击完成后，按照该区域的“完成后等待”范围随机等待，再执行下一个区域；不叠加区域内点击间隔。
所有时间使用秒作为输入单位，最多支持 3 位小数，每次按 1 毫秒步长随机取值。
例如 N=2、M=1.5，填写 `2.000～3.500`，即在 2000～3500 毫秒之间随机等待，包含端点。
等待范围上下限相同表示固定等待；区域完成后等待允许 `0～0`，表示不额外等待。
计时从上一条点击的 ADB 命令返回后开始。实际触发时间受操作系统调度及 ADB 开销影响，不保证 1 毫秒执行精度。
最后一个区域使用轮间隔进入下一轮，其“完成后等待”不叠加；最后一轮结束后直接完成任务。
轮间隔从上一轮完成后计算，因此每轮开始时间差包含上一轮执行耗时；第一轮也会等待。
相同上下限表示固定值；坐标上下限包含端点。坐标原点在设备屏幕左上角。

例如 A 完成后等待 1.200～1.800 秒、B 完成后等待 3.000～4.500 秒：
每轮先等 20～22 秒，点击 A，等 1.200～1.800 秒，点击 B，等 3.000～4.500 秒，点击 C，随后进入下一轮等待。
移动区域时等待配置跟随该区域。加载旧配置时，原来的全局区域间隔会自动填入每个区域；新配置保存为版本 2。

截图缩放只影响预览，框选结果转换为设备实际像素坐标，支持向任意方向拖动。
“添加此区域”会直接加入执行列表；“仅填入主界面坐标”用于修改已有区域，返回后需点击“更新选中”。
也可以在主界面手动填写坐标并添加区域。截图为采集时的静态图片，手机页面变化后请关闭截图窗口并重新采集。
开始前会读取屏幕截图并检查所有区域边界；运行期间请保持屏幕方向、分辨率及目标页面不变。
折叠屏请同时保持折叠状态不变，切换内外屏后停止任务、刷新屏幕并重新框选区域。
截图明确指定物理屏幕 ID，点击使用这块物理屏幕当前对应的逻辑屏幕 ID；屏幕选择会随配置保存。
未点亮的屏幕会提示切换屏幕，不继续显示黑图。屏幕列表依赖设备 `dumpsys display` 中的物理/逻辑屏幕映射。
本工具不识别界面元素，也不会自动唤醒或解锁设备。运行期间配置锁定，停止后再修改。
停止可以立即中断等待，但已发出的 ADB 命令需返回或超时（15 秒），已发送的点击无法撤回。
ADB 失败会终止任务并显示错误，不会自动重试点击。

## 验证

```powershell
python -m unittest discover -s tests -v
python -m compileall -q adb_clicker.py click_engine.py tests
```

自动测试使用模拟 ADB，不会向手机发送真实点击。连接设备后的点击效果需在目标手机确认。
